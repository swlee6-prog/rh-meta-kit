# Claude Code 데스크톱에 소재 작업 맡기기

1. 작업대의 **Windows 시작 ZIP**을 내려받아 모두 압축 해제합니다.
2. **Claude Code 데스크톱에서 압축을 푼 폴더를 엽니다.** 일반 Claude 웹 채팅에 ZIP을 첨부하는 방식이 아닙니다.
3. **소재 폴더와 원하는 작업을 말합니다.** Claude가 동봉된 `CLAUDE.md`를 읽고 파일 검사부터 업로드·결과 확인까지 진행합니다. 동봉된 CLI가 오래됐으면 Claude가 서버의 검증된 최신 파일로 교체한 뒤 진행합니다.

## 이렇게 말하세요

```text
이 폴더의 CLAUDE.md를 읽고 [소재 폴더 경로]의 영상으로 [참조 광고 이름] 설정을 그대로 유지해 [대상 광고 세트 이름]에 새 PAUSED 광고 1개를 만들어 주세요.
새 광고 이름은 [이름], 언어는 [영어]로 해 주세요.
```

예전에 정한 대상이나 참조는 다시 적지 않아도 됩니다. 기존 작업을 계속하려면 “하던 작업을 이어서 확인해 주세요”라고 말하세요. 생성 전에 확인하고 싶다면 “초안 업로드까지만 준비해 주세요”라고 말하면 됩니다. 명령·광고 번호·설정 JSON은 직접 입력하지 않습니다.

이어하기나 결과 확인은 Claude가 기존 이력부터 찾습니다. 이미 완료됐거나 제출 후 진행 중이면 원본 폴더를 다시 요구하거나 같은 광고를 새로 만들지 않습니다. 업로드가 남았고 원본 위치를 찾을 수 없을 때만 폴더를 확인합니다. 설정 파일과 증빙은 작업별로 보관하므로 이전 파일을 직접 수정하거나 삭제할 필요가 없습니다.

실패한 작업은 자동으로 다시 제출하지 않습니다. 재시도를 명시적으로 승인한 경우에만 Claude가 `submit OPERATION_UUID --confirm-new-paused --supersede-failed PREVIOUS_OPERATION_UUID` 명령을 사용하며, 백엔드가 이전 작업의 완전한 종료와 creative·광고 미생성, 영상 이외의 불명확한 외부 요청이 없음을 확인해야 허용됩니다. Meta가 거절한 요청(FAILED)이나 미확인 영상만 있는 실패도 허용되지만, 생성됐거나 생성됐을 수 있는 creative·광고가 있으면 허용되지 않습니다. 같은 검수본·파일·광고명의 `ASSETS_READY` 초안이 이미 있으면 그대로 사용하고 광고명도 바꾸지 않습니다. 생성 여부가 불명확하면 새 작업을 만들지 않으며, 백엔드의 거절을 우회하지 않습니다. 이미 받은 재시도 승인은 다시 묻지 않습니다.

제출 응답이 기존 중복 작업을 가리키면 Claude는 반환된 `operation.id`의 상태와 증빙을 확인합니다. 요청한 초안과 반환된 작업 번호를 구분하고, 요청한 초안이 새로 제출됐다고 보고하지 않습니다.

## 연결은 필요할 때만

이미 연결된 PC면 저장된 인증으로 바로 진행합니다. 처음이거나 만료·취소됐을 때만 Claude가 브라우저 연결을 시작합니다. 열린 작업대에 회사 계정으로 로그인하고 Claude에 표시된 코드와 같은지 확인한 다음 **이 기기 연결에 동의**를 누르세요. 코드가 자동 입력돼도 자동 승인되지는 않습니다. 본인이 시작하지 않은 요청은 승인하지 않습니다.

Claude가 연결 완료를 확인하므로 토큰을 복사할 필요는 없습니다. 코드는 10분 안에 승인·수령하며 한 번만 사용합니다. 연결은 완료 후 7일 유효하고, 작업대의 **연결 및 개인 토큰**에서 취소할 수 있습니다. 만료됐으면 Claude에게 다시 연결해 달라고 말하세요.

## 준비할 것과 결과 확인

- PC에 **Node.js 22 이상**과 로컬 파일·터미널을 사용할 수 있는 Claude Code가 필요합니다. Node.js가 없으면 <https://nodejs.org/en/download>에서 설치하고 Claude Code를 다시 여세요. 자동 설치나 관리자 권한 요청은 없습니다.
- 소재는 이 PC에서 접근할 수 있는 폴더에 둡니다. 현재 등록된 게임(Rabbit Hole·Card of Demon Slayer)의 **9:16·1:1·16:9 MP4 한 묶음**, 파일당 최대 512 MiB를 지원합니다. 이미지·playable·미등록 게임은 지원하지 않습니다.
- Claude는 지정한 폴더 안에서 실제 영상 크기와 회전을 확인합니다. 영상이 빠졌으면 다른 폴더의 비슷한 파일로 채우지 않고 필요한 원본 경로만 한 번에 묻습니다. 후보가 여러 개이거나 게임·영상 내용이 불명확하면 필요한 구분만 묻습니다. CDN 주소를 추측해 원본을 찾지 않습니다.
- Claude는 이름 확인 명령으로 전체 목록에서 대상과 참조가 각각 하나인지 확인합니다. 같은 이름이 여러 개면 설정이 같아도 첫 후보를 고르지 않고 캠페인·상태 등 구분할 정보만 한 번에 묻습니다. 광고 번호 입력은 요구하지 않으며 목록 조회가 끝나지 않으면 임의로 선택하지 않습니다.
- 이미 승인한 설정을 유지하는 작업에는 같은 승인을 다시 묻지 않습니다. 참조가 바뀌었으면 Claude가 작업 상태와 기존 생성 기록을 확인하고 차이를 짧게 설명합니다. 변경 설정을 사용하려면 새 검수와 새 초안이 필요할 수 있으며, 기존 업로드를 그대로 재개할 수 있다고 미리 약속하거나 참조 광고를 대신 되돌리지 않습니다.
- **마케터 검수 대기**는 Meta 심사 승인이나 집행 시작을 뜻하지 않습니다. 최종 집행은 Ads Manager에서 검수한 뒤 결정합니다. 중단되거나 심사 중이면 같은 광고를 다시 만들지 않고 기존 작업을 확인합니다.

결과는 상태·소재 결과·증빙·필요한 다음 행동을 3~5줄로 안내합니다. 오류가 나도 원인과 필요한 확인만 짧게 묻습니다. 테스트 환경에서 확인한 결과는 실제 광고 생성과 구분해 알려드립니다.

브라우저 연결이 어려울 때만 작업대의 접힌 **토큰을 직접 입력해 연결하기** 안내를 사용합니다. 토큰은 사람이 직접 연 CLI login의 숨김 입력에만 넣고 Claude 채팅이나 파일로 전달하지 않습니다. Windows 인증 저장에는 로컬 NTFS 사용자 프로필이 필요하며 권한 오류는 관리자에게 문의하세요. 자세한 안전·복구 절차는 Claude가 `CLAUDE.md`에서 읽습니다.
